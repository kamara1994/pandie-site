UPLOAD TALENT MEDIA HERE — one set of files per child, named by their id
from /data/talents.json:

  {id}.jpg   poster photo, portrait 4:5 (e.g. 720x900), under ~300KB
  {id}.mp4   talent clip, 10-15 seconds, 720p max, ~2MB or less
  {id}.vtt   captions for the clip

Example for Musa (id "musa-m01"):
  musa-m01.jpg   musa-m01.mp4   musa-m01.vtt

IMPORTANT: strip location (EXIF/GPS) data from photos & videos BEFORE
uploading. On iPhone: Share -> Options -> Location OFF.

The cards show a branded initial tile until these files exist — upload,
push/deploy, done. To add or remove a child, edit /data/talents.json.
